# 戦闘比較記録

`combat-readability.json` は、同じ初期セーブと60 Hzの入力時刻から、攻撃予兆・入力・被弾・受け流しを再生する検証記録です。`npm run review:combat` で再生成し、同じ入力を二度実行して結果が一致することも確認します。

収録する比較は、近接攻撃に何もしない／回避／受け流し、ボスの衝撃波に地上で留まる／跳躍する、の5条件です。ゲーム内の戦闘表示と同じ `combat-presentation.js` を記録に使います。

これはルールと表示用データの自動検証です。実際の画面、タッチ、音、端末性能、攻撃が見やすいか、操作が間に合うか、面白いかは確認しません。通常のセーブへ読み込む用途ではありません。
