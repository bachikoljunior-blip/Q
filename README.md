# Q — 灰の巡礼

スマートフォン向けオープンワールドアクションRPG。独自のファンタジー世界「灰冠の地」を探索する、第一章「残り火の谷」の開発版です。

世界の火を集めた王冠は、王を失ったまま燃え続けている。巡礼者は三つの灯火を取り戻し、北の門に待つ番人を倒し、火の行く先を選びます。

**現段階は初期実装です。ユーザーが指定した10作品と同等の品質に達したとは判断していません。** 現在の確認範囲、未達項目、制作の続きは [制作状況](docs/PROJECT_STATE.md) に記録しています。

## 遊ぶ

- [プレイ版を開く](https://q-ash-pilgrim.juurooo.chatgpt.site)（所有者限定）。
- タイトル画面は先に軽量表示し、「旅を始める」「旅をつづける」またはセーブ読込を選んだ時点で3D世界を読み込みます。タイトルへ戻った後は3D描画を休止します。
- PCでは [単体起動版](release/Q-ash-pilgrim.html) をダウンロードし、WebGL 2対応ブラウザーで開くこともできます。単体版は外部CDN・画像・音声への通信を必要としません。
- スマートフォンはプレイ用URLから開いてください。横向き・縦向きのレイアウトを実装しています。ストア向けのAPK/IPAはまだありません。
- セーブは端末のブラウザーに保存します。消費したスタミナ・残火、回復や攻撃の途中、敵の残り体力と矢も引き継ぎます。旧バージョンのセーブも読込可能です。ひとつ前の正常な記録を残し、保存が壊れた場合に復旧します。タイトルからファイルを読み込むこともできます。「旅の記録」からJSONで書き出し・読み込みができます。

## 実装済みの遊び

- 高低差のある約740×502 mの移動範囲、集落、森、水殿、廃塔、北の門、西の白塩の段丘。遠景の山脈、川、橋、草木、昼夜の移り変わり。814本の木の幹は見た目と同じ位置で移動・矢・カメラを遮ります。
- 入力の先行受付、剣・槍・大剣の三段連撃、スタミナ、無敵時間付き回避、方向とタイミングを使う受け流し、跳躍、範囲攻撃「残火」、対象の注視。武器ごとに射程・攻撃速度・消費・攻撃範囲が変わります。
- 獣、兵士、狙いを定めて矢を放つ弓兵、体力によって行動が変わる地域ボス。攻撃の予兆、ひるみ、障害物を迂回する追跡、帰還。敵は合計30体。
- 11個の宝箱、50個の露草、巡礼の遺物。経験値、レベル、安全な灯火での三系統の強化、敵のいない場所での霊薬の調合。霊薬は飲み終わると回復し、途中の被弾・回避で中断します。
- 灯守ミラとの会話と遺物の配達、三つの灯火の奪還、休息・高速移動、死亡と再出発、二つの章末選択。章を終えても探索可能。
- 渡し守セナの分岐クエスト「川の向こうの約束」。橋を渡って東岸の荷車を奪還し、薬草の届け先を選ぶと、霊薬の効果・補充数・そこに暮らす人、会話、集落や野営地の様子が変わります。旅人側の薬箱は安全なときに霊薬を4本まで補充できます。
- 鍛冶師レンと薬師イオは時間帯に応じて仕事場や灯火へ歩き、敵が近づくと避難します。近づくと足を止めて話せます。集落を選ぶと回復した人と荷運びが生活へ戻り、旅人を選ぶと橋の野営地に巡回者が現れます。
- 探索クエスト「風の入らない炉」。西の三響の祠で碑文を読み、鳥・雨・星の鐘を順に鳴らします。音を使わず文字としるしでも解けます。レンに報告すると「風渡りの鈴」を受け取り、回避の消費が25から21になります。鐘の途中経過と住民の位置も保存します。
- 西の「白塩の段丘」と探索依頼「運び手の帰り道」。琥珀の森の西で伝言板を読み、北の岩棚か南の塩原を迂回して見張り場の取っ手を回収します。巻上げ機を直すと石門が開き、実際に通れる近道になります。帰還報告と報酬は一度だけで、開通状態も保存します。旅の記録からこの依頼を追えます。
- 石門が開くと、伝言を書いた運び手ナルが見張り場・貯水槽・谷側を往復します。開通報告の前後と章末の選択で会話が変わり、帰還報告後は谷側に荷が届きます。ナルの移動途中も保存されます。
- タッチ、キーボード、ゲームパッドの入力処理。描画品質、音量、視点感度、被ダメージ軽減の設定。
- プレイヤー・ミラ・セナ・近接兵にKay LousbergのCC0モデルと骨格アニメーションを導入。剣・槍・大剣、歩行・走行・回避・霊薬の動作を共通制御します。他の住民・獣・ボス・環境は独自の簡易形状、音はWeb Audioによる手続き生成です。造形・演技・音響は商業大作の品質には達していません。

## 開発

Node.js 22.12以降または対応する新しい版を使います。この制作環境ではNode.js 24.19.0で確認しています。

```bash
npm ci
npm run dev
npm test
npm run test:journey
npm run test:crossing
npm run test:forge
npm run test:session
npm run test:expedition
npm run build
npm run package
npm run test:artifacts
```

開発サーバーはViteの出力するURLを開きます。通常環境でスマホ確認する場合は同じネットワークからPCのアドレスへ接続します。公開用の静的出力は `dist/`、外部依存が不要な単体版は `release/Q-ash-pilgrim.html` です。Sourcesと生成物を変更したら両方を更新してください。

Three.js 0.186.0を固定しています。[描画にはWebGL 2が必要](https://threejs.org/docs/pages/WebGLRenderer.html)です。Vite 7.3.1を固定し、package-lock.jsonを管理しています。配信版ではThree.jsと3Dシーンを遅延チャンクへ分け、単体版ではネットワーク不要の1ファイルへ再結合します。ゲーム状態は60 Hzの固定ステップ、描画はrequestAnimationFrameです。多数の木・岩・草はInstancedMeshで描きます。この制作環境では実機のフレームレートは未測定です。設定の「この端末での動作」は、遊んでいる間の実フレーム間隔を計測し、JSONで書き出せます。画質と画面サイズを変えた場合は別の計測としてやり直します。

第三者のコードのライセンスは [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) を参照してください。

人物素材の出所・固定版・加工内容は [素材記録](src/assets/characters/provenance.json) に保存しています。`scripts/prepare-characters.mjs` に記載の版から再生成できます。配信版ではモデルをゲーム開始時に読み込み、単体版では同じデータを埋め込みます。

完成期限は2026年9月20日です。完成条件と残る検証は [完成までの作業](docs/COMPLETION.md) に記録します。

配信用の作業ディレクトリは、容量を二重に使わないよう生成物へのハードリンクを使う場合があります。生成物は配信完了まで変更せず、再ビルドしたら `npm run test:artifacts` で作り直してください。
