# Q: STARTHREAD

一指で重力点を動かし、機体との間に張った光の糸で敵を切る、スマートフォン向けアクションゲームです。

## Play

https://bachikoljunior-blip.github.io/Q/

## Controls

- 画面を押す: 指先に重力点を作り、機体を引き寄せる
- 押したまま動かす: 軌道と光の糸を動かす
- 指を離す: 現在の勢いで滑空する

全8区画。強化を選び、中間ボスと最終ボスを倒すとエンディングです。広告、ログイン、外部APIはありません。
