# Q: WILDBOUND

森、草原、川と湿原、雪峰、海岸、洞窟、集落、遺跡がひと続きになった谷を旅する、スマートフォン向け3DオープンワールドRPGです。

## Play

https://bachikoljunior-blip.github.io/Q/

WILDBOUNDは現在、公開前の検証ブランチです。上記URLは品質基準と実機確認を通過するまで従来版STARTHREADを配信します。

## Journey

- 三人称視点で約1,800 × 1,800ユニットの谷を自由に探索
- 7つの主要ランドマーク、採集資源、NPC、篝火、鍛冶強化
- 剣、回避、気力、生命力、レベル、経験値、三体の守護者と最終ボス
- メインクエスト、永続する選択と結果、エンディング、終了後のフリーローム
- バージョン付きローカルセーブ、自動保存、オフラインキャッシュ
- 外部API、ログイン、広告、外部ランタイム素材なし

## Controls

スマートフォンでは左パッドで移動、ゲーム画面のドラッグでカメラ、右側のボタンで攻撃・回避・調べるを操作します。

PCでは `WASD` / 矢印キー、マウスドラッグ、`J` / `Space`、`K` / `Shift`、`E` が使えます。
