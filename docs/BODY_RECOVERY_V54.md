# Mira upper-garment candidate, recovery v54

**Disposition: not adopted into runtime.** The integration owner rejected this candidate because the very small visible conversation change does not justify changed contact pairs and increased crossings in reused animation API stress cases. The candidate commit and exact evidence are retained for inspection; no subsequent redesign is authorized in this unit.

This is a newly constructed source-guided geometry candidate on recovered base `fa920db9782b7df42e4e16099a05994e5841dbaa`. The lost v42 implementation and its old results are not recovered or used as acceptance evidence. Only Mira (`npc`) torso and sleeves change. Real Scene Mira uses idle animation; dialogue changes the camera, not her pose. Walk, arm raise and reach below are reuse/stress checks.

The pinned, saved CC0 MakeHuman hm08 artist-authored body supplies angular transverse contours. No new download, morph, image, scan, texture or body mesh is introduced. Source joint distances are registered to the existing Q rig, then each section is bbox-centered and normalized to existing garment radii. Source anatomy, authored garment ease and UV mapping are different things: this method does not measure fabric thickness or establish anatomical correctness. See the dedicated provenance for source scale, arm axial changes, raw contour radii, clamping and weighting. The shoulder-adjacent sleeve row uses an isolated upper-arm section at fraction .34; the direct shoulder plane would also include the torso and is not presented as an isolated arm sample.

The initial candidate introduced new proper triangle crossings with lower cloth, front leather bands, closures and staff/cuffs. Its exact generator/data/results are retained under `rejected-initial`. The final constrained candidate fixes the first three torso rows, collar and front attachment hemisphere; only the back contour receives the cosine-weighted source change. Sleeve contours retain their original inner envelope and add bounded source-derived fullness. This is a deliberately limited shape change, not a whole-body reconstruction.

Fresh author checks preserve all 483 target vertices / 816 triangles, 161 original connection vertices exactly (additional attachment vertices are also held), indices, weights, all bones, head/hands and other 13 role families. Target positions change on 105 vertices: maximum torso 17.42 mm, sleeves 5.64 / 5.37 mm. All original y rows and garment endpoints remain fixed. No inverted or degenerate face was introduced. Five identical author pose fixtures add no new target-face / external-mesh contact classification; existing overlaps remain. The author key is target face plus external mesh/material, not the external triangle ID, so it does not establish unchanged triangle pairs within a mesh. This author oracle also excludes upper-garment-to-upper-garment pairs. The independent reviewer separately checks actual triangle pairs and broader animation conditions.

Physical-length UV charts replace row-index spacing on the three pieces. Whole repeat counts close their wrapped seams, with shared density and unchanged texture/materials. P95 UV Jacobian anisotropy changes from 3.111 to 1.998 on the torso and 3.398 to 1.917 / 1.924 on sleeves. This is a numerical reduction in stretch, not rendered weave approval. Density statistics and seam phase are retained in the evidence; chart boundaries against other garments still require real visual assessment.
