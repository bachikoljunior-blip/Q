# Q soundscape integration — 2026-09-15

This change implements an original electronic score and synthesized foley. It is not a real orchestral recording, human instrumental performance, captured environment, or a copied score. Stock music was considered through the available HeyGen catalog; its returned tracks had no item-level license establishing redistribution in a game. The official terms at https://www.heygen.com/terms did not resolve that scope. No stock track was downloaded or used, no voice clone was made, and no third-party sound samples were imported.

## Exact main integration API

- `await audio.start()` must originate in an existing trusted user gesture. It resolves `true` only when the AudioContext resumes and that lifecycle generation remains current. Web Audio unavailable, resume rejection and cancelled resume return `false`. Other existing callers may ignore the returned Promise. `audio.active` / `audio.status` expose observed state; `status` can be `locked`, `running`, `suspended`, or `disposed`.
- Explicit title sound: `audio.setMode('title'); const ok = await audio.start(); if (ok) audio.play('titleStart');`. Do not label a blocked resume as audible success. `setMode('title')` alone never unlocks or resumes audio.
- Main play frame: call `audio.update(game, delta, { cameraYaw: view.yaw, paused })` after simulation. It infers exploration/combat with four-second threat release hysteresis, samples distance-driven footsteps, selects earth/stone/wood/water, handles landings, places water and lit-place fire in stereo, and varies wind. It only reads game state. Remove the old `walkTimer` noise/vaultStep emission to avoid duplicate steps; the new vault footstep is one of three stone atlas variants.
- `setMode('exploration'|'combat')` is available for explicit scene transitions. `tick(time, combat)` remains as compatibility only; new integration should use `update()`.
- Keep `play(event.type, event)` for gameplay events. Enemy IDs are resolved to positions for panning and distance attenuation. Player weapon type selects sword, spear or greatsword whoosh/impact. `play('uiFocus'|'uiConfirm'|'uiBack')` supplies UI signatures. `play('death')` fades the pulse and lowers score volume.
- Settings: `setVolume(0..1)`, `setMusic(boolean)`, `setMuted(boolean)`, `setBusVolume('music'|'ambience'|'sfx'|'ui',0..1)`. Existing `music = boolean` is a setter with the same effect. Persist preference values using the existing settings store; this audio module writes no storage.
- On pause, blur, hidden, pagehide and return to title, call `suspend()`. It stops/disconnects all sources, invalidates pending starts, clears reverb history, and suspends the context. Resume only by an explicit existing gesture. `dispose()` permanently clears buffers and closes the context.
- `setVault`, `vaultSfx`, `tone`, `noise`, `fileSound`, and `loadAsset` remain available. Vault loop requests still receive independent sources per generation so stale ABA requests cannot silence re-entry; one-shot decode bursts remain deduplicated. File one-shots older than 350 ms or from a cancelled lifecycle are discarded.

## Packaging and gates

`src/soundscape-asset-urls.js` statically imports the three MP3 stems, one WAV atlas and cue JSON. The root-owned standalone esbuild loader must include `'.mp3': 'dataurl'`; Vite supports the static media imports. Include the four assets listed by `src/assets/soundscape/provenance.json` in source/dist/stage/standalone exact-byte checks. Total runtime encoded payload is 1,499,890 bytes. The review MP3 in docs/evidence is not runtime payload.

CI needs only `node scripts/verify-soundscape.mjs` (standard Node modules) and the normal `npm test` glob. Local authoring reproduction requires the exact NumPy/SciPy/ffmpeg toolchain recorded in provenance: `python3 scripts/generate-soundscape.py --verify`. MP3 identity across arbitrary encoder versions is not promised. `python3 scripts/analyze-soundscape.py` decodes the committed files with ffmpeg, measures the signal and creates the offline preview.

## Memory, lifecycle and evidence limits

The new decoded assets occupy 18,587,052 bytes at the authored 22.05 kHz. AudioContext is requested at 22.05 kHz; an overriding 48/96 kHz device decoder is compacted back to 22.05 kHz before caching. Long stems decode sequentially. The cache cap is 24 MiB; buffers larger than the cap are rejected. The physical browser decoder may transiently allocate a device-rate buffer before compaction: the largest 48 s stereo stem is 18,432,000 bytes at 48 kHz or 36,864,000 bytes at 96 kHz, in addition to retained data and a new 8,467,200-byte compact output. Browser codec internals / garbage collection and real device peak RAM have not been measured. Existing finite vault assets and runtime short noise/impulse buffers remain additional allocations. The tests use an explicit 48 kHz device/decode mock and check that all three stems and foley coexist under the cache limit.

At most 36 live voices are tracked; title normally has three score and three atmosphere loops, with one extra loop inside a vault. Overflow retires the oldest short voice. All voice nodes disconnect on natural end, suspend or disposal. There are no timer-driven perpetually accumulating nodes. The PCM atlas uses 24 authored cues; ordinary actions do not allocate a new noise buffer.

`audio-score-review.mp3` is an offline 48 s music-only mix: 0–16 title, 16–32 exploration, 32–48 combat, with 1.5 s transitions. It is suitable for media playback, but is not captured gameplay, a real Web Audio render, or a claim of having heard a physical device. `audio-signal-qa-20260915.json` records source decoding, zero clipped samples, exact 48 s stem duration, RMS/peak and loop continuity. `soundscape-lifecycle.test.mjs` bundles the actual production Soundscape with real asset imports and mocks only fetch/Web Audio contracts. It validates graph connections and scheduling, not audio quality, autoplay behavior on actual Safari, game FPS, real-world spatial perception, or commercial-score quality. Formal device listening and the fixed ten-work quality comparison remain unverified.
