# Independent v54 review conditions

Base is recovered PR51 `fa920db9782b7df42e4e16099a05994e5841dbaa`; baseline source is checked against its Git blobs before execution. The author alone edits runtime. This review writes only its scratch directory and reads already installed Three dependencies. Old v42 outputs are unavailable and are not acceptance evidence.

Fourteen CPU conditions: bind, initial idle, idle at 1.5 s, idle at 3 s (dialogue-equivalent skeleton), ignored-emote API at 1.5 s, walk, run, turning, sword wind/release, spear release, greatsword release, parry, and an explicit arm stress pose. The real Scene calls Mira with `{moving:false}`; only idle is her current shipped motion. Dialogue changes camera composition, and there is no separate emote skeleton clip. Other motions/stress are reuse/deformation checks, not claims of Mira production actions. Roots are matched; rendering and visual perception are absent.

Target: original main-cloth 483 vertices /816 triangles (torso 171/288, each sleeve 156/264). Original required fixed boundaries total161 vertices (torso first2 +last row; sleeves first2 +last2). Check their native skinned world positions are exact, all non-target positions/attributes and all weights/indices are exact, all bones and binding matrices exact, and all other13families match hash for idle/walk/attack. Thus head/neck/hands/grips and the actual connection boundary are preserved; pre-existing gaps are not called closed.

Each target triangle is checked against corresponding baseline orientation and area. UV signed areas must remain positive/nonzero; wrapped positions and normals must close, and U-span times existing repeat4 must remain an integer. Area-weighted Jacobian anisotropy and density use native posed triangle dimensions and existing64-pixel procedural map ×repeat4. No new material is inferred.

An independent segment-triangle test checks each garment triangle against every visible native skin/rigid/cape triangle, including nonadjacent target self contacts. It excludes shared-index neighbours and boundary/coplanar contact; broad-phase AABBs only reject disjoint pairs. Proper crossing face counts, pair IDs and new/removed positions are retained. This measures intersection existence, not overlap depth or a cloth solver, and the many existing intersections remain explicit.

Final candidate is evaluated only after author fixed source hashes arrive. Unchanged contracts are hard checks; contact changes require identifying the actual parts before an acceptance recommendation. Increased triangle count is not quality evidence. Source plane/bounds reproducibility, artist-authored garment ease and motion deformation are assessed separately; no anatomical scan, cloth fit or PS4-quality claim is accepted.
