## BOMとの整合で残る設計項目

読取時の `STAFF_MICRO_BOM.json` は数値を作者設計値と明記している。この前提を保持し、画像のpixelsを実寸としない。

- **S13** は現在 `horizontal torus / major_radius=17 / tube_radius=3`。この定義なら外半径20、内半径14、高さ6 mmだが、円形管断面の単純トーラスは新画像の平たい外壁・面取り・内段とは同じ形ではない。新画像の外形を正本にするなら、BOMのformを環状lathe断面へ明示更新し、外径/孔径/厚み/段を作者設計値で固定する。外形資料が改善したことを、旧TorusGeometryのままで一致するという意味にしない。
- **S14** は現在 `closed stepped cap / y1663–1678 / max_radius18`、S15のstemは半径6、y1674–1681 mm。外形と受口を一つの閉じた表面にできるが、「closed」が穴無しの塊を意味するのか、穴を含む閉じたmesh表面なのかを曖昧にしない。受口の径・座面深さとS15の挿入境界を設計値で固定する。新画像に写らない内部を既に確認済みとはしない。

この2項は同じ部品の仕様を明確にする作業で、新しい意匠や任意の追加生成を要求する理由ではない。元のauthor寸法を変更する場合も数値の設計変更として記録し、画像から精密に採寸した値と称さない。
