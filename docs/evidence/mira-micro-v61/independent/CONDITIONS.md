# 微小部品一式 — 独立判定条件

目的は、画像生成側が完成像を**すべて揃う小さい部品**へ分け、その部品を短い実装単位で実3D化して組み立てられるようにすること。大きな「上衣一式」「頭一式」を小部品と呼び換えない。部品を細分化したこと自体を品質向上とせず、集合した輪郭・厚み・曲面・しわ・顔・髪の詳細を完成像へ戻して一致させる。

## 台帳と画像に必要な対応

| 確認対象 | 必須情報と失敗条件 |
|---|---|
| IDと実装単位 | 1つのIDが1つの作る形状を指し、用途と境界が明確。例：袖一式をそのまま1IDにせず、接合境界を定義した局所面や巻き帯へ分ける。実装に再び形の設計・別パーツの発見を要するものは未分解。作成所要時間は後の実作業で記録し「一瞬」を未測定で保証しない |
| 全体網羅 | 完成図の各見える領域が、ちょうど一つの表面IDまたは意図した重なりへ対応する。左右の瞼/眼/指/靴、後頭、襟後ろ、腋、裾裏、灯具裏も一覧化。髪/身体/衣服等のグループIDは集計用とし、同じ面を親と子で二重制作しない |
| IDと図の一意対応 | 各部品のID、正面/側面/裏面、親グループ、完成図上の位置を対応させる。全体の分解図にも同じIDを付ける。別図で同じIDの形・数が変わる、別IDが同じ部品を重複する、画像ラベルが判読不能なら未確定 |
| 原点・軸・左右 | 全体と各部品の原点、顔前/上、本人右左、画像から見た右左、unitを固定。完成FRONTとBACKで杖を持つ手・留め具・髪分け目を追跡。既存sourceのright命名と画面左右は同義ではない。左右鏡写しの共用品は元ID・複製先・反転軸を明記 |
| 寸法と曲面 | 全体寸法と、各部品の幅/高さ/厚み・曲率または輪郭断面を対応させる。接合側の寸法も必要。単に画像倍率を揃えるだけでmm値を確定しない。生成画像に描かれた数字・目盛も台帳と照合し、物理測定済みと扱わない |
| 隣接と接合 | 各接合を `partA.edgeX ↔ partB.edgeY` の対として示し、向き、接合長、接続後の位置、隙間または意図した重なりを記録。取り付く相手のない辺、1辺を複数の矛盾した相手へ接ぐ指定、表裏反転を検出する |
| 層順と不可視面 | 肌→下地→衣服→留め具等の局所層順を固定。見えない裏面/穴/内周は「画像未提示・仕様として決定」か「補完必要」かを明示。襟・腰のように別シートが同じ部品を所有しない。縫い代や接着面を外観表面と二重に数えない |
| 可動部 | 各部品の追従boneまたは相手、固定/曲がる境界、曲げる向きを示す。眼と瞼、首と襟、肩と袖、手首と巻き革、指と杖、膝と裾で、隣接部品が動いた時の形を必要な少数姿勢で照合。細分化だけでrigや衝突を解決したと扱わない |
| 全部を合わせた完成像 | 部品図とID付き分解/組立図を往復し、部品の追加・削除・別形状への置換なしで固定完成像へ戻るか確認。完成像に必要な面が「実装時に適当に補う」状態なら一式は未完。単体部品が良くても全身比率や接合が違えば全体一致とはしない |

最低限の台帳1行は **ID / 親グループ / 対応画像とview / 本人左右 / 共用・鏡写し規則 / 全体内の位置・姿勢・縮尺 / 幅高厚・断面 / 隣接IDと接合辺 / 外内・層順 / 可動先 / 完成図対応領域 / 未確定点**を持つ。台帳と画像で一方だけ存在するIDを残さない。

## 有限の確認手順

1. **棚卸し**：ID重複、欠番の意味、グループと実部品の区別、左右の個数を確認。意味不明の連番の数だけを網羅率としない。
2. **組立関係**：接合の相互参照、孤立部品、二重所有、鏡写しの誤り、見えない裏面の扱いを確認。骨格付き身体に直接つくものと衣服に重なるものを区別する。
3. **実画像の照合**：完成像→分解図→各部品の角度図→組立図を実見する。全体の6方向と、今回の首/腋/腰/握り/足底のような必要接合だけを使う。外観のない帳尻合わせを画像一致と呼ばない。
4. **不整合の返却**：追加画像が必要なものを具体的なID/接合/角度で返す。既存正本の指定や台帳の訂正で解けるものまで再生成しない。全体設計の変更が必要なら明示し、知らないうちに完成像を取り替えない。

判定は `未提示` / `矛盾あり` / `設計判断を明示して固定可能` / `資料間整合を確認` の4状態で残す。画像だけの最後の状態も、実3Dの実装・物理寸法・接合・動作の合格とは異なる。形状を単純な箱・円錐へ落として資料の細かさを消す方法を、「小部品化したので同じ完成品」と正当化しない。

現時点では微小部品台帳・一式画像が未提示のため、部品網羅/一致の判定はまだ行っていない。大粒度v60の7枚は完成像・衣装の背景資料であり、微小部品一式の検証済み成果に流用しない。後のnative幾何図は、固定された頂点と行列から作る設計図としてのみ比較に使い、WebGL材質・光影・実ゲーム画面・PS4品質の代替合格にしない。
