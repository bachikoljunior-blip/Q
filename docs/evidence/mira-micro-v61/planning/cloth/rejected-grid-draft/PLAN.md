## 生成資料へ必ず載せる接合情報

各小片は完成図中の位置・部品ID・正面/裏面/側面・斜め1方向・4辺IDを持つ。折れ線や厚みのない平面片なら不要な視点を増やさず、単一の曲面を確定できる最小セットにする。素材模様は形状の根拠と分け、無関係な飾りを追加しない。

最重要の境界は `parts.json` の `interfaces`。首/上衣/外cowl、左右armhole、袖/手首、腰上下/帯、ズボン/靴の相手を固定する。Armholeの脇区画は新参照で切欠きの位置を決め、境界制御点を双方へコピーする。同じ接合edgeの位置・接線・法線・skinweightリストを1つにし、別々に推測してから押し込んで隠さない。布を細分化しても骨やdrawを小片数だけ増やさず、組立て後に接合をweldして既存material batchへまとめる。

先行資料の順序案は、1)脇と袖付けの少数隣片、2)立襟/cowlの少数隣片、3)単一腰接合と帯、4)袖/手首、5)外套側面、6)下衣開き/裾、7)残りの規則区画と金具。これは**全資料の準備順序**であり、資料一式が整う前に大きな造形へ戻る指示ではない。資料の矛盾を解消してから、1片の作成/境界照合→同型片の配置→全体組立てへ進む。

候補の腕・cowl・cape交差は今後の実CPU接触/画面比較で再検証が必要。微小部品数や細かい参照が揃っただけで完成像一致、自然な変形、PS4品質やiPhone SE3性能が合格するわけではない。この草案は統合担当が他の頭・手・靴・杖の部品表と接続して確定する。
