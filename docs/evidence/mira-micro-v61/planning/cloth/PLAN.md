# Mira衣装：単純な曲面型から組み立てる資料草案

最新の「全部組み合わせたら完成品になる、短時間で1つ作れるほど細かい部品を先に生成する」指示に対応する。**任意の格子212片案は棄却**し、形状上の役割を持つ34の参照型候補・79配置インスタンスへ整理した。素材模様や配置位置だけの違いは別型にしない。旧案は `rejected-grid-draft/` に不採用理由と共に保全し、正本へ流用しない。

座標正本は **本人のRight=−X、Left=+X、前=+Z**。camera+Zからの正面画像では本人Rightは画像左。既存arm/hand番号0=−X、1=+Xは配列番号として扱い、人体左右の名前に読み替えない。旧案の「+X本人右」は誤り。

この草案で画像生成・造形・runtime変更は0。各小片の寸法は現Rigを基点とする概数で、生成絵から測ったCAD寸法ではない。型ごとの実制作時間も未測定のため「一瞬」を実績として保証しない。

## 用意する画像資料の現実的な単位

1sheetに最大4型、各型は正面・裏/側・斜めの必要最小視点と端点ラベルを置く想定なら、34型は概算9sheets。加えて接合資料3sheets（首襟/cowl/cape、肩脇/曲げ袖、腰上下/belt/開き）で**概算12sheets**。これはまだ生成していないページ数の案で、9や12を必要絶対数や制作時間の実績にはしない。小さすぎて辺を読めないsheetは分ける一方、対称反復だけの別画像は作らない。

1sheetごとに完成像中の位置、型ID、3Dで使う外輪郭/断面、隣のedge ID、厚みと重なりを対応させる。単純な押出なら断面1つと側面で確定でき、無意味に全方向図を要求しない。表裏や左右で輪郭が違う曲面は省略しない。反対側を同じ向きで描いた旧cape-v1の問題を繰り返さない。柄や陰影は形状とは別に扱う。

全体の正本は既存完成像。型を独立に格好よく変更するのではなく、その完成像に組み上がる輪郭・寸法・隣接関係を先に確定する。資料一式/接合が揃う前に旧大粒度造形へ戻らない。

## 共有境界と旧候補の扱い

- 首：既存chest-local neck原点(0,.600,0)、collar top y.644、opening半径(.089,.083)mは頭担当との引継ぎ値。新neck-cutと実接触を合わせて確定する。
- 袖付け：左右各16点の共有armhole loopを、前/後crescentとsleeveの対応edgeへ分配する。同一edgeに位置/接線/法線/skinweightを1組だけ持たせる。
- 手首：chest-local x±.313,y−.18m。clothing cuffとaccessory handの所有を分け、wrapを二重追加しない。
- 腰：chest-local y約.020m、半径(.216,.145)mの単一腰線。上衣の短い自由裾を二重露出させず、上下の端をbeltの下へ接ぐ。
- 靴：既存knee-local y−.095mのズボン/靴接続をaccessory担当と共有する。この衣装案で脚の元skinを勝手に動かさない。
