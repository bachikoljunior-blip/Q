寸法・形・接合先・既存候補再利用可否は [parts-draft.json](parts-draft.json) に1部品ずつ記録した。数値は既存頭座標から置いた仮のパッチ範囲で、生成画像から物理校正した値ではない。画像を固定する前に最終寸法へ昇格させない。座標は頭local、+Y上、顔+Z。camera+Zから正面を見ると+Xは画像右＝本人左なので、人体R=−X/L=+Xとする。固定完成像の本人右手・杖は画像左=−X。旧コードのside/bone命名とは区別する。以前の「+Xが人物右」はこの微小資料内で訂正した。画像のLEFT/RIGHT印字だけで左右を決めない。

部品画像は、固定された完成像の「この場所のこの形」であることが分かる配置小図と、当該部品の正面・側面・接合面を示す。独立した鼻や髪を自由生成して、似ているという理由だけで寄せ集めない。同じ顔の曲率、左右、前後の重なりを一組の設計に固定する。部品ごとの確認に不要な衣装・背景・装飾は混在させない。画像のラベルだけを接合保証にはしない。

最初の画像検討は、完成像の印象を決める小鼻/鼻梁、片側の頬骨パッチ、一束の前髪などから始められる。各部品の基準境界を確定したら、隣の部品も同じ境界を使う。62個を同時に新規造形する指示ではなく、統合担当が順序と画像セットを確定するための一覧である。

皮膚は一つの連続メッシュとして成立させる。共有の境界ループには同じ頂点位置とUV端点を使い、合わせ目の法線は溶接後の隣接面から計算する。UVの分裂頂点も幾何位置・必要な滑らか法線を一致させる。鼻孔・唇・耳の自然な稜線は意図して残す。別々に簡略化したパッチを貼り合わせると境界がずれるため、全体を接合してから境界固定のLODを作る。目と口の内面を塞がず、瞼には既存の二骨と閉眼幅を適用する。

髪の一束は閉じた短いスイープ形状として作り、球殻にノイズだけ加える代用はしない。束の根は頭皮に潜らせて接合を隠し、隣束の稜線や重なりは残す。62制作部品を62描画メッシュにする必要はない。接合後の皮膚は一つの既存材質バッチ、髪は一つの共有材質バッチへまとめ、独立部品の作者データと描画単位を分ける。

旧候補の再利用は個別に判断する。元CC0頭とUV、眼・首・骨、皮膚パッチのトポロジーは再利用しやすい。現在の意味制御で作った顎/鼻/頬や24髪束は仮の形状テンプレートであり、新しい微小部品資料と一致した証拠はない。側面輪郭、法線接合、閉眼、首/襟接触を部品単位と完成組立ての両方で確認する必要がある。原肌のstubble等は別の未採用素材問題であり、部品化で解決したことにはしない。

ここでは画像生成・新造形・runtime編集・外部取得・browser・配信を行っていない。完成像の一致、ゲームでの自然さ、端末性能、PS4品質の合格も主張しない。


## 固有型と配置instanceを分離する訂正

62個は組立instance数。微小画像に必要な固有形状は、現分解での**実用上の最小案30型**（顔11/頭皮4/耳3/眼瞼3/眉1/首2/髪6）。左右対称部は1型＋mirror、同じ髪の曲線系列は1型＋限定変形/配置に分ける。数学的最少や一致確認済みの型数ではない。同じ関数で作れるだけの理由で、鼻梁と頬骨など違う見える形の画像を省略しない。

| 髪の固有型 | instance ID | 保持する形の違い |
| --- | --- | --- |
| HT01 横流し前髪 | H01–H04、H09–H10 | 浮いた根、主方向の弓なり、薄い先端。短い前縁は同系列の短縮 |
| HT02 頭頂の浅い重なり束 | H05–H08 | 低く幅のある断面、浅い曲率、重なり稜線 |
| HT03 側頭の短い流れ | H11–H12、H14–H15 | 頭皮に沿う下向きの短い湾曲 |
| HT04 耳際の終端 | H13、H16 | 耳へ向かう短いtaperと輪郭の切れ目 |
| HT05 後頭の長い流れ | H17–H20 | 頭頂から後頭へつながる長い弧と小さなねじれ |
| HT06 襟足の先端 | H21–H24 | 細い下向き終端、少し外へ逃げる先端、揃いすぎない下端 |

同型でも根/中間/先端・幅/厚み・許容曲率・ねじれ・前後重なりをinstanceごとに指定する。24個の単純コピーや同じ太さの束にはしない。型の特徴が変わるほどの曲げ伸ばしは同型扱いを中止する。各型の正面・側面・接合面を1枠として、1ページ3型なら10ページという発注案になる。62ページを意味せず、生成済みでもない。細部や継ぎ目が読めなければページを分割し、形を省略して詰め込まない。

正本head FRONT/TOPを再実見すると、分け目は画像右＝本人左(+X)、前髪は画像左＝本人右(−X)へ流れる。旧44477候補のguideは負X根→正X先で逆向きなので、その配置のまま再利用してはいけない。曲面/taperの作成方法だけを再利用候補に残し、新微小資料は根+X→先−Xを規定する。旧source/commitは書き換えていない。眼の色も正本は灰青であり、旧茶色の虹彩を一致済みと扱わない。

全30型と62instanceの対応は [type-manifest.json](type-manifest.json)、各instanceの人体左右と再利用制限は [parts-draft.json](parts-draft.json) に記録した。境界頂点・UV・法線・閉眼・首接合の条件は前述を維持する。

左右mirrorは作者データの形状再利用であり、完成メッシュへ負スケールを残す指示ではない。座標へ反映した後に三角形winding/外向き法線を確認し、対応する左右の原UVを保持する。元画像を鏡像貼付して顔の左右差を潰さない。正本で左右差が読める部位は、同型の配置補正・境界制約として明記し、必要なら固有型を分ける。
