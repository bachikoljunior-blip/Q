2. **cape の実際の反対側と内側肩接合。** capeシート上段 LEFT PROFILE と RIGHT PROFILE は、どちらも前開き・brooch 側が画像左にある同方向に見える。対向する側面の証拠にはならない。完成シートの鼻が画像右を向く RIGHT PROFILE に対応する、前開きが画像右になる cape 側面と、その肩内側の接合を追加する。本人左右のラベルだけでなく「顔前方向」「背中心」を示す。浅い背面の hood 状の垂れが **被らない cowl/back drape** であるなら、それを正本の設計として固定する。画像だけでは実際に被れる hood の容量は確定できない。

補完依頼は同一衣装の欠落情報だけに限定し、顔・体格・杖・服の意匠を描き直す機会にしない。先に親と作者へ上記2系統を通知した。作者の「短い裾をbelt下へ二重露出させない」「被らないcowl」という解釈は整合可能だが、画像で確認済みの構造とは区別する。

## 実装へ渡す固定規則

画像の FRONT / LEFT / RIGHT は視線方向と本人左右の解釈が混在し得る。+Z顔前、本人の左右、staffを持つ右手を一度対応させて部品表へ記す。複数パネルは同じ縮尺の投影図とは限らず、pixelsをそのままmetresへ変換しない。全身で相対寸法を固定し、部品図の局所detailをその寸法へ収める。

顔/髪、襟/cowl、上衣/下衣、手/杖を異なるシートから切り貼りしただけで接合を完成扱いにしない。head側と衣装側で首回りを二重所有しない。完成図の袖・腰・襟を接写と同時に比較し、首/肩/腰/手首/足首の見える隙間を実3Dで検査する。生成資料に合わせるため既存目印を黙って移動せず、現行顔ランドマーク固定の方針を維持する。

このレビューは画像読取とhash照合のみ。画像生成/編集、source編集、browser、render、remote操作は0。画像の全体的な自然さや実ゲーム/PS4品質の合格ではない。補完された図の確認と最終canonical固定は後続の有限境界で行う。
