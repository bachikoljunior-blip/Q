## 完成像への配置・層順

完成像と garment-assembly を優先すると、肌首 → 立襟 C01/C02 → 外側 W01/W02/W03 → 肩接続 P04 と外套、上衣 T/S → 腰接合 → split 下衣 L、最外の革 belt B、内側の trousers TR と靴、という所有が読める。上衣の短い完成部品図の裾をそのまま下衣の上へ二重に露出させず、canonical assembly の一つの腰接合を正本とする。カウル後部の垂れを頭に被せる追加 hood としない。

`COVERAGE.json` は T02-R/L と F03 各 3 本を本人 Right=-X / Left=+X へ明示的に登録している。誤文言・locator は捨てると文書化され、画像を正しく修復したことにはしていない。B02-R / B03-hanger-R は旧 ID のまま、本人 Left(+X) への訂正案を別属性に保存している。canonical 正面の吊帯位置と一致する方向の訂正で、runtime を変更した証明ではない。

上衣・外套の大きなシルエット、襟の内外順、前 split、左の吊帯、左右の bracer を、この型分類が明白に逆転させる新しい矛盾は確認しなかった。ただし 30 選択画像を並べたことは、96 配置を組み合わせて完成像の形になる実証ではない。帽子状に閉じた背面、衣服全体を一型にする図、余計な二重 layer は、選択しない古い行や画像から持ち戻さない。
