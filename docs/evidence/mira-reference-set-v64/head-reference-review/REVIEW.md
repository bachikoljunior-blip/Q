## 完成像・左右・全体組立

canonical の完成像と頭図は短い灰髪、本人左側の分け目から右へ流れる前髪、裸の首から衣装へ続く人物像を共有する。選択した各画像は概ねその部位を指しており、別人物の大きな装具や髪型を新しく所有させる明白な変更は確認しなかった。ただし、単体の clay 図と個別 locator を並べたことは、40 型を配置した頭が同一顔になる証拠ではない。頭図と全身図自体にも髪の見かけの量・倍率差があり、顔の絶対同一性は保証しない。
