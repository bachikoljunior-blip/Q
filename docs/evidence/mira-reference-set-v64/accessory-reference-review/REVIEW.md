- **AB10縁帯**：TOP/UNDERSIDEは閉じた足形、SIDEは直線状の細い表示。平面リングを横から見れば線に重なる場合もあるため、これだけで位相矛盾と断定しない。ただし本底の反りに追従した側面とは未確認。既存除外を維持する。

全型の資料完備を閉じる場合は、AH08/10の除外で消えた必要角度も補う。全面を作り直す依頼ではなく、該当1型の未確定面を限定する。

## 完成像・左右・全体組立

完成像/手資料の本人右は杖を握り、本人左は弛緩している。型画像は孤立した開いた部品なので、実際の右手把持を表していない。本人右=actor−X/hand-0、本人左=+X/hand-1を保持し、同じ画像の単純鏡映で皮膚境界・骨・法線まで完了としない。母指variantや内外の足型はさらに別の調整を要する。

canonicalの低い踵、革の脛筒、折返し、巻き革、爪先の基本構成とは大分類で対応する。新画像の独立した皮膚の太い縁、靴の金属リベット、余計な留具まで完成像へ追加してよいことにはならない。原画の巨大表示から実キャラクターのmmやPS4品質は導けない。

90配置のID/型対応は完全に照合できたが、共有曲線の接続は別問題。AH10→cloth F01/F02のWRISTは重なりであり、皮膚と布を同じ頂点へweldする契約ではない。ズボンとAB07/08も布の差込みと空隙が必要。固定資料の両手首/両靴上端4portはすべてtransform/curve/clearanceがnull、validated=falseのまま適切に残っている。後発ズボンleaf案はこの固定90配置へ無断では追加しない。
