## 全被覆を主張しない補完

E03は上瞼のみ。E04下瞼・E05内眼角・F18眼窩下を追加し、眼球周囲の欠落を旧額/頬で塞がない。F19鼻唇側面・F20口角・F15鼻柱/鼻孔底を追加し、鼻/唇の間を未定の大きな補面で埋めない。A04耳裏/根元を追加する。A01→A01a外縁+A01b内側分岐、A02→A02aくぼみ+A02b耳珠、F16→F16a上唇+F16b人中へ分ける。これにより旧30型に追加7型、分割による純増3型で40型。旧62配置に追加13配置、分割純増5配置で80配置となる。

頭皮4型は、前/頂/左右/後の5配置という原計画を保持する。首N01/N02は一枚ずつの前半周/後半周で、左右の4枚へ勝手に増やさない。髪6型/24配置は形の反復候補であり、同一型でも根元・湾曲・先端・重なり順の個別登録が必要。全24本の絶対配置は今回の代表例画像にはまだない。裏面/鼻孔/耳入口/口腔内部、表情時に見える面も、今回の40型だけで完成している保証はない。

既存 raw 6型は F01/F05/F09（v60）、F07/F11（v63）、F17（base645より後のcheckpoint014bdddf）。すべて条件付きのまま。v63の実7面の共通辺検証が成功したことを、生成画像が精密な同一物体投影である証明には流用しない。F01とF05の間には眼窩があり、直接weldしない。

## 寸法・接合・可動の未確定

coverage.json の寸法は旧仮envelopeを出所付きで保全し、finalMillimetres/rootTransform/seamCoordinatesをnullとした。未測定の値を画像pxから補完していない。conceptualJoinsは隣接案であり共通曲線の確定値ではない。下記INTERFACES.mdでweld、接触、重なりを分ける。法線、UV、骨割当、目の開閉、口の閉じ目、耳/鼻内部の可視判定、首襟接合は実装・比較前。

全人物の資料固定は独立ledger/統合審査に残る。完成像との正確な一致、すぐ作れるという実時間、実ゲーム/WebGL/iPhone/PS4品質を、この画像数や台帳件数から合格にしない。

## 出所と時間

全画像は builtin image_gen.imagegen による架空の原画。canonical完成像/頭画像を参照し、新しい外部写真・scan・assetは取得していない。Pythonはraw copy/hash/PNG decodeと台帳生成のみ。画像の画素加工は正式imagegenの限定修正だけ。19新PNG合計38,564,383 B（公開/HTTP転送計測ではない）。tool原path、開始/返却時刻、選択v1/v2、PNG寸法・hashを記録した。

TIMING.json は仕様/計画開始から最終保存までのwallと19callのrequest→return区間を区別する。call区間にはprompt保存とtool調停を含み、純粋GPU生成時間ではない。残りwallも検査専用時間ではなく、判断・連絡・台帳保存を含む。3D造形・修復・geometry比較・実画面検証はいずれも未着手。

COVERAGE.md/coverage.json、inventory-check.json、raw-images.json、HASHES.jsonを入口とする。inventory-checkはファイル/件数の整合だけで、幾何/画像品質テストではない。原19PNGと旧6型の3PNGを保持し、この有限単位を閉じる。
