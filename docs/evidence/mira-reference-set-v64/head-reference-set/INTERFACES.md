skinの鏡像は同じ人物の左右同一保証ではない。生成全身・頭正本を照合し、最後に左右差を調整する必要がある。髪全体を左右反転しない。明示的な左右型以外のN01/N02/F12等を、生成の都合で片側型へ変更しない。
