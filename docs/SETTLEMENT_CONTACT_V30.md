# 住宅基礎・橋取付の接地 — v30

基点 `16af6cf6a744c36e7e9f45720fa8e7fb922c9069`。住宅4棟と橋2本の接地だけを改修した。実装は original authored geometry で、新しい外部素材・画像・音・ライセンスはない。建物の root、屋根、壁、扉、窓、住民、道路、既存通行床と2D衝突・保存を保持する。住宅の縦方向の遮蔽下端だけは、新しい基礎に合わせて広げる。

住宅は一律高さの石板を、同じ 5.7 × 4.8 m の地形に沿う連続基礎へ置換した。外周の下端は `heightAt − .12 m`、天端は元の `.5 m` と地表上 `.18 m` の高い側を採る。ただし扉正面の幅1.44 mは local `.12 m` の低い notch として、奥まった扉下端を隠さない。斜面へ埋まっていた壁の下部は地下壁として保持し、外側を石の基礎で覆う。家を持ち上げて扉を浮かせる変更はしない。基礎内部の底面 fan は深く埋めており、その埋没量を外周の浮きと混同しない。

橋は既存の `groundAt` と同じ高さを 1 m × 1.325 m 以下の格子で標本化した厚み .16 m の ramp に置換した。元の梁・板を保持し、板間の床下 .008 m に連続床、両端に幅 .045 m の端材を設けて接続穴を閉じた。橋ごと3横梁・6柱を既存木材の1 meshへまとめる。柱の footprint は全て既存 deck の地面遮蔽範囲内で、柱上端も通行床以下。川底や岸の地形へ入り、水面を通って既存梁へ接続する。見える柱のために新しい collider を追加する必要はなく、橋下に通行可能な新しい空間を設ける変更もない。

## 同じ条件の数値比較

実 `SceneView.createStructures/createWater` が作る native Three.js mesh と、実 indexed terrain の三角形を使用した。renderer は起動していない。旧 scene・environment-models・core の source を hash 付き fixture に保存し、cherry-pick 後に旧ローカル commit が存在しなくても比較を再現できる。

| 対象 | 旧 | 改修後 |
|---|---:|---:|
| 住宅同一 2,624 点 × 4 棟の底面最大浮き | +1.063216 m | −.020518 m |
| 住宅外周 324 点 × 4 棟の底面 | 旧面取りのため同じ外縁では多数欠落 | −.142999〜−.097538 m |
| 住宅基礎天端の外周地面からの最小高さ | 一部地下 | +.168967 m |
| ramp 内部 741 点 × 4 面、通行床との差 | −.133078〜+.147762 m | −.004287〜+.004299 m |
| deck/ramp 接続 760 点の ray が通る穴 | 196 | 0 |
| 接続部と通行床との差 | 最低 −.591607 m、穴を除外 | −.008000〜+.001409 m |
| 新しい柱中心 12 点の底面対 terrain | 支持なし | −.130573〜−.097941 m |
| 構造＋水 mesh 数 | 205 | 205 |
| 同範囲三角形数 | 65,596 | 67,124（+1,528） |

住宅の .1 m grid は旧基礎で実交差した同じ 2,624 座標だけを両版で使う。外周比較は浮きと接地を調べる別の集合で、元の面取り形状の欠落を数値的に同一面と扱わない。ramp 内部集合から厳密な端の Float32 丸めを除き、端は別の接続集合で検査する。最大 .004299 m は標本化した実三角形と解析的通行床の差であり、数学的な完全一致ではない。

## 扉と窓

扉前面 80 ray、窓の下端・中央・上端 24 ray で、最初に見える material と world Z が旧版と一致する。基礎以外の6 material の全 position 配列も一致した。扉前面は基礎の前縁より手前にあり、新しい石で敷居や窓を塞いでいない。以下は扉中心と前縁の実 ray/terrain 値（m）。

## 独立指摘と修復

最初の基礎は扉下端の薄い暗色縁を最大8.8 mm手前の石で隠した。独立した位置・角度を変えた ray で発見し、入口 notch で修復した。最終の独立360 door / 480 window rayでは、元から見えていた扉や窓を石が覆う例は0。残る石→石の交差位置変化は notch 自体の形状変更であり、全形状の不変とは説明しない。

下へ伸ばした石の露出部分は、元の住宅 collider 下端より下にあり、旧44短線で実 projectile が44件、camera が22件すり抜けた。このため認可済みの限定 core 修復を行った。Three.jsに依存しない `houseFoundation` が実基礎の下側輪郭と obstacle 下端を共用し、既存 v29 の `obstacleCylinder` を通して camera・実 projectile・forecast へ届く。保存した旧44線は改修後に全て wall 接触・camera 遮蔽となり、同じ旧 Game では projectile 44件の負例を再現する。上端・2D位置・半径は変更しない。

地形ごとに基礎を組む際、最初の版は上物6 materialの geometryまで住宅ごとに複製した。実 buffer 数を測って共有へ戻し、構造＋水の一意な geometry buffer は 2,542,136→2,855,048 B（+312,912 B）。複製版5,178,056 Bから2,323,008 Bを除去した。mesh数は維持する。この容量は CPU attribute配列の計算であり実GPU計測ではない。

## 検証と限界

[独立監査の実ray・source hash・旧負例と最終readback](evidence/settlement-contact-v30/independent/audit.json) を保存した。

最終258/258 tests、13 commandすべて成功（実command合計66.873秒）。初期 JS は 164,447 B（上限 165,000 B）、3 chunks、全JS962,828 B。最初の7 command/258 tests成功後、独立指摘を修復して必要13 commandを再実行した。音・人物の実行コードや 8,000 tri / 14 draw の人物契約は変更していない。core変更は pure helper import と住宅4件の y/height 初期化に限定し、元上端 `heightAt(center)+6 m` を保持する。x/z/r・他 obstacle・敵・pickup・fresh save は実旧 Game と比較して一致した。公開用生成物は親の結合時に再生成する。

[evidence](evidence/settlement-contact-v30/geometry.json) は source hash と全位置の集計、[最終 gates](evidence/settlement-contact-v30/final-gates.json) は実 command・所要時間を保存する。最終回は窓と同一点集合の補強、入口 notch、縦遮蔽修復の後に再実行した。旧 geometry が float/ramp error/接続穴の負例に実際に該当することも検査する。

正式 WebGL 画面・スマートフォン FPS・実 camera の見え方・触感は未確認。形状の接地検査は、自然な石積みや橋の造形、人間の印象、全画面 PS4 相当の合格ではない。期限 2026-09-20 の品質達成をこの局所改修から保証できない。元の固定 slab と2三角形 ramp の限界に対して、実通行床と地形に沿う形状へ方法を変えた有限単位として統合し、次の未解決品質へ継続する。
