# Death entry recovery v52

The player now retains the last displayed bone and attached weapon pose when a real live death starts, blends to the existing death pose over 0.24 s, then uses the original canonical death path exactly. This is a finite pose-continuity repair after workspace recovery. It does not establish natural animation, screen quality, device performance, or PS4-equivalent quality.

## Lifetime and source contract

The real Scene passes the same `Game.player` object without an explicit death clock. Its first death frame therefore has `deathAge = render dt`. The new cache holds the 44 unique existing node transforms and four quaternions, plus fixed bookkeeping. It observes player identity without modifying Game state. It is bounded per actor, inactive after 0.24 s, and invalidated by an alive frame, changed player object, changed equipment, or an explicit finite death clock. First-seen and explicit-clock corpses stay canonical. A real dead save restores through Game's existing respawn path; it is not a settled corpse load.

The attached weapon's combined orientation is interpolated once and the right wrist solved from it. This avoids applying cancelling wrist/weapon rotations twice. The grip parent and local position remain fixed. A weapon hidden while drinking has no previously displayed orientation: its reappearance uses the canonical death orientation while the body blend continues. Actual equipment changes immediately before a lethal hit use that same visibility rule. This is not a visibility crossfade or a zero-pop claim.

The first reconstructed actor was byte-identical to the previously recorded v40 runtime SHA `e23fb1c5…`, 38,088 B. That match is limited to this source file and its recorded hash; the lost old commit and old validation were not recovered byte-for-byte. Fresh independent testing found a required defect in that source: healing with a spear introduced first-frame rigid ground gaps of −433.040/−474.101/−480.813 mm at 30/60/120 Hz. The source and failure are preserved under `rejected-hidden-spear/` and `independent/rejected-*`. The final visibility repair is a new change, not a claim that the old PASS covered these cases.

Corresponding native mesh vertices are compared within each condition; cross-rate action phases are not assumed identical. No renderer or browser was run.

All 36 first steps improved; all 36 final one-second poses equal baseline exactly. The former initial jump is distributed into the short blend, so later individual steps increase even though the maximum over the complete measured fall decreases. This residual fast motion must not be called natural or eliminated. At the artificial zero-dt API boundary, skin/rigid move about 5 mm from existing ground support and cape moves 21.186 mm; actual Game entry normally has positive dt.

The author additionally sampled 180 surface conditions: 3 weapons × 4 actions × 3 real terrain locations × 5 early death phases. Each visible triangle used vertices, edge midpoints and centroid. Minimum skin/rigid/cape gaps were +2.613/+155.872/+28.801 mm; no sampled negative gap. This evaluates native actor triangles against analytic `groundAt`, not a proof for every triangle interior, rendered terrain facet, location or time.

[Independent review](evidence/death-entry-recovery-v52/independent/REVIEW.md) newly executed 27 additional conditions: heal/jump/naturally vulnerable dodge tail × 3 weapons × 3 rates, without overriding invulnerability. All 27 continuously visible entry steps improved, all serialized/player states were unchanged, and one-second poses matched fresh canonical and baseline actors exactly. Sampled minimum skin/rigid/cape gaps were +1.698/+24.624/+11.986 mm; the hidden-spear regression was eliminated. The maximum continuously visible entry steps by prior action were heal 1.020729→0.223692 m, jump 1.690190→0.075299 m, dodge-tail 0.918017→0.298967 m.

The independent report retains a separate union metric including hidden-to-shown coordinates: healing's maximum grows 3.323408→3.956738 m. A hidden vertex did not occupy a visible pixel before death; this metric is not used as displayed-pop evidence. The existing Game freezes an airborne dead root: the jump fixture remains 1.094167 m above terrain, identically in before/after. This existing failure to land is not repaired here. Existing cape/body intersections and cape entry treatment are also not repaired.
