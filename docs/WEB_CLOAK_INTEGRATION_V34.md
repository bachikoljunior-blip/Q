The normal owner-only play URL is the primary deliverable. The former mandatory single HTML release is optional. This removes the repository's 16 MiB Git-data/HTML publishing guard from art acceptance; it is not a larger service quota or lower device-memory cost.

## Same-material method decision

The retained delivery study separates code-request phases from actual HTTP: raw shell inputs about 396 KB, world-start additions about 6.69 MB, conditional title video 3,178,191 bytes, gesture-triggered score/foley 1,499,890 bytes. No HTTP compression, Range/cache behavior, latency or mobile peak memory was measured. The next separately authored v35 unit moves 34,380 bytes of distant vault images out of the initial awaited set and isolates their failures. It still loads all four near the new-game area, so it does not reduce total media bytes.

Web remains the selected delivery method because the existing URL already supports multiple files and this change is directly compatible with its access contract. A PWA cache needs explicit quota, version and authenticated-logout behavior. A native wrapper retains renderer/device work while adding signing and distribution. A new engine requires a game/render/save port and unmeasured mobile verification. None is treated as an automatic quality or September 20 shortcut. No new service, fee, audience or automation was introduced.

The physical cloth study rejected a fine cotton diffuse-only substitution for limited projected benefit and unsuitable outer-cloak material, independently of the old HTML budget. Future fitting PBR assets may use the Web route; their GPU and loading costs still require explicit assessment.
